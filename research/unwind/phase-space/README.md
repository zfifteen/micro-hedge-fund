# Unwind Phase Space

Round-3 research object.

Most market talk asks a confused question: *is AI a bubble?* This folder refuses that object.

## The object

The Unwind object is a **finite evidence machine**:

- six clocks (token prices, GPU rental, circular paper, spender cash, rim credit, hub mark)
- event floors that force danger **4** or **5**
- recovery conditions that can lower danger only when no upward floor is live
- an honesty wall named **`measured_wall`**

**Hypothesis cannot raise official danger.** Only Measured clocks and Measured event flags move the score. That is the same species of honesty Prime Gap Structure named with `profile_wall` — adapted to finance-loop evidence.

## Dual ledger

| Ledger | May raise official danger? |
|---|---|
| Measured conflicts + Measured events | Yes |
| Hypothesis overlays / secondary commentary | No |

YouTube, desk streams, and macro essays can sit on the Hypothesis ledger. They inform questions. They do not mint a 4.

## What `phase_space.py` computes

1. Official danger under the honesty wall
2. Measured-only vs Hypothesis-only danger (proof Hypothesis is inert)
3. **Minimal certificates** for danger ≥ 3 (smallest Measured conflict sets that force Stressed)
4. **Minimal paths to Fragile (4)** and **Unwinding (5)** from the current clock state
5. **Minimal conflict-drop sets** to heal back to soft ≤2 or ≤1
6. JSON + markdown reports for automation and humans

## Run

```bash
pip install -r requirements.txt
python3 phase_space.py --clocks clocks.yaml --out out
```

Open `portrait/index.html` for the interactive ontology portrait.
